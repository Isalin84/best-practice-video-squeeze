# Best Practice Video Squeeze

Локальный компрессор видео для быстрых отправок в Telegram. Приложение работает через FFmpeg на вашем компьютере: исходный файл не загружается в облако.

## Что исправлено

Некоторые записи экрана macOS после масштабирования превращались, например, в `1919×1080`. H.264 требует чётные размеры кадра и завершался с ошибкой `-22 (Invalid argument)`. В текущей версии масштабирование использует `force_divisible_by=2`, поэтому такие файлы обрабатываются автоматически.

## Возможности

- перетаскивание видео или выбор файла через Finder / Проводник;
- четыре профиля: Telegram / быстро, Telegram / баланс, Качество, Минимальный файл;
- MP4, WebM и MOV;
- настройка CRF, разрешения и сохранения звука;
- прогресс обработки, сравнение размера до и после;
- повторная компрессия исходника с другими параметрами;
- сохранение результата рядом с оригиналом или в выбранную папку;
- ссылка на студию Best Practice AI внутри приложения.

## Установка

Готовые установщики публикуются во вкладке [Releases](../../releases):

- macOS: DMG для Apple Silicon и Intel;
- Windows: установщик NSIS и portable-версия.

Установщик содержит FFmpeg и FFprobe для своей платформы. Отдельная установка FFmpeg не требуется.

## Сборка локально

Нужны Node.js 20+ и npm.

```bash
npm ci
npm run check
npm run dist:mac
```

Для Windows:

```powershell
npm ci
npm run check
npm run dist:win
```

Сборка Windows и macOS запускается автоматически через GitHub Actions при создании тега `v*`. Подробности находятся в `.github/workflows/release.yml`.

## Важно о подписи

Сборки GitHub Actions готовы для установки, но без сертификата Apple Developer и сертификата Windows Authenticode операционная система может показать предупреждение от Gatekeeper или SmartScreen. Это не влияет на работу приложения; для публичного распространения сертификаты можно добавить в секреты репозитория.
